# Four-Second Fixed-View Video Prompts

Read only after explicit storyboard approval, or when the user supplies final approved images and asks for prompts.

## Authority and rules

- Keep approved `B01...` order and numbering.
- The approved image is the exact first frame and controls visible identity, outfit, room, products, light, composition, and viewpoint.
- Source evidence controls the action, hands, pose, head/gaze/expression changes, rhythm, and result.
- One image produces one four-second continuous fixed shot with one main action and only necessary micro-actions.
- The action must be physically reachable from the first frame and end in the recorded handoff state.
- No cuts, camera movement, zoom, reframing, focus change, viewpoint switch, or scene change.
- Do not add action to fill time. If a complete unit cannot fit naturally, return to planning: split at a physically reachable complete-action boundary, or obtain explicit approval for longer duration. Never drop a necessary causal result or accelerate unnaturally merely to fit four seconds.

Before using the template, validate the selected image version, approval and explicit video-prompt request with the structured contract. For a user-approved duration/camera exception, replace all conflicting four-second/fixed-camera clauses consistently, use the approved values, and label the adaptation; do not retain contradictory instructions in the same prompt. If source content is placed within a letterboxed container, distinguish content-frame preservation from the final output container.

## Copyable template

Put `### B01｜短标题` outside its own code block:

```text
【视频主题】
[本镜头的动作目的。]

【上传图片锁定｜最高执行】
Use the uploaded image as the exact first frame.
保持同一人物、脸、发型、服装、产品、环境、光线、构图和固定视角。

【4秒动作】
[从可见起始状态开始，一个主要动作及其必要接触、物体变化、可见结果和自然收尾；遵循来源视频的姿势、视线、表情与节奏。]

【固定机位与连续性】
Vertical 9:16, realistic UGC smartphone footage, 4 seconds, one continuous fixed shot. 保持人物身份、脸部可见性、服装状态、手部归属、产品外观与状态、房间布局、物体位置和光线连续。动作符合人体结构、接触关系和现实物理。

【禁止项与声音】
No cuts, camera movement, zoom, reframing, viewpoint or scene change, identity/hairstyle/outfit/product mutation, extra limbs, deformed hands, floating or teleporting objects, repeated or padded action, background change, global recolor, blue light cast, subtitles, usernames, platform UI, TikTok watermark, unsupported text, invented logo, or BGM. 仅保留自然环境声和动作声。
```

Verify exact first frame, one reachable main action, natural four-second completion, causal result, fixed camera, stable identity/outfit/room/product/light, and no unsupported content.
