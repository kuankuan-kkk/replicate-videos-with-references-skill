# Default Profile

Use these defaults only when the user has not specified otherwise. Copy resolved values into the project manifest so another session can continue without chat history.

| Area | Default |
| --- | --- |
| Frame | Vertical `9:16` |
| Base-image count | Natural complete-action count |
| Test batch | Exactly the count requested by the user |
| Video per approved image | 4 seconds |
| Video camera | One continuous fixed view |
| Texture | Preserve observable source UGC phone-camera character |
| Cleanup | Offer removal of subtitles, usernames, platform UI and watermarks as explicit authorized edits |
| Continuity | Identity, face visibility, outfit, accessories, room, product, hands, object state, direction, and light |
| Approval | Storyboard approval required before video prompts |
| Output language | Match the user's language; video prompt template defaults to Chinese |

Do not silently turn recurring personal aesthetics into universal defaults. Blue/white palettes, pink décor, extreme body proportions, iPhone model, third-person staging, or a fixed storyboard count require current-project instructions or an explicitly selected preset.

When a user's broad request leaves a low-impact visual choice open, choose one restrained continuity scheme and record it. Ask only when the choice materially changes identity, product truth, story, architecture, or expected deliverables.

9:16, four seconds and a fixed camera are defaults, not permission to violate source locks or omit action results. For incompatible sources follow [structured-state-and-gates.md](structured-state-and-gates.md), record the user's decision, and use the resulting per-action contract.
